\#### System Roles as Contextual Framing The \`system\` role sets the social and functional relationship between the user and the agent. The exact same user input produces completely divergent outputs depending on the system context. For instance, the statement \`"I love you"\` processed under: - A \*\*romantic partner\*\* persona yields reciprocal emotional validation. - A \*\*corporate enterprise manager\*\* persona triggers professional boundary enforcement and workplace communication protocols.
